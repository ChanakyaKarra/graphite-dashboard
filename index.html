⬡ Live Data Integration Guide
Step-by-step instructions to connect this dashboard to live pricing and energy data from the internet
Architecture Overview

This dashboard is a self-contained HTML file. To make prices update automatically from the internet, you need a thin server-side layer that fetches data from APIs and serves it to the dashboard. The dashboard already has all the logic to consume and render it — you just need to supply the live numbers. Three options, in order of complexity:

Option A · Serverless
Google Sheets + Apps Script fetches APIs and populates a JSON endpoint. Free, no infrastructure.
Option B · Node.js API
Small Express server (Vercel/Render free tier) fetches APIs every 6 h and caches JSON. Recommended.
Option C · Python Backend
FastAPI or Flask app with scheduled jobs. Best for enterprise / authenticated data sources.

Step 2 — Build a Data Proxy / Cache Layer
⚠ You cannot call most APIs directly from the browser (CORS restrictions + API key exposure). A server-side proxy is required.
2a
Option A — Google Apps Script (zero infrastructure)

Create a Google Sheet with electricity/coke price data. Attach an Apps Script that fetches public APIs on a time trigger and writes to a published JSON web app URL. The dashboard fetches that URL directly.

// Google Apps Script (Tools → Script Editor) function fetchAndPublish() { const eia = UrlFetchApp.fetch( 'https://api.eia.gov/v2/electricity/retail-sales/data/?api_key=KEY&...' ); const data = JSON.parse(eia.getContentText()); const sheet = SpreadsheetApp.getActive().getSheetByName('live_data'); sheet.getRange('B2').setValue(data.response.data[0].price / 100); // $/kWh // Repeat for other fields... } // Set trigger: Edit → Triggers → Every 6 hours // Web App endpoint returns JSON: function doGet() { const sheet = SpreadsheetApp.getActive().getSheetByName('live_data'); return ContentService.createTextOutput(JSON.stringify({ usa_elec: sheet.getRange('B2').getValue(), eu_elec: sheet.getRange('B3').getValue(), coke_price:sheet.getRange('B4').getValue(), updated: new Date().toISOString() })).setMimeType(ContentService.MimeType.JSON); }

Published URL format: https://script.google.com/macros/s/YOUR_DEPLOY_ID/exec

2b
Option B — Node.js API on Vercel (recommended)

A 30-line Express app deployed to Vercel free tier. Fetches APIs server-side, caches for 6 hours, serves CORS-enabled JSON to the dashboard.

// api/live-data.js (Vercel serverless function) let cache = null, cacheTime = 0; export default async function handler(req, res) { res.setHeader('Access-Control-Allow-Origin', '*'); if (cache && Date.now() - cacheTime < 6 * 3600 * 1000) { return res.json(cache); } const [eia, fx] = await Promise.all([ fetch(`https://api.eia.gov/v2/...?api_key=${process.env.EIA_KEY}`).then(r=>r.json()), fetch(`https://openexchangerates.org/api/latest.json?app_id=${process.env.OXR_KEY}`).then(r=>r.json()) ]); cache = { usa_elec: eia.response.data[0].price / 100, inr_usd: fx.rates.INR, eur_usd: fx.rates.EUR, updated: new Date().toISOString() }; cacheTime = Date.now(); res.json(cache); } // .env: EIA_KEY=xxx OXR_KEY=xxx // Deploy: vercel deploy --prod
Step 3 — Wire Live Data into the Dashboard
3
Add this fetch block to the dashboard JavaScript

Replace the static LOCS electricity rates and MATS cost with live values. This code runs on page load and again every 6 hours.

// Add near top of <script> section const LIVE_DATA_URL = 'https://YOUR-VERCEL-APP.vercel.app/api/live-data'; // OR Google Apps Script URL: // const LIVE_DATA_URL = 'https://script.google.com/macros/s/DEPLOY_ID/exec'; async function fetchLiveData() { try { const res = await fetch(LIVE_DATA_URL); if (!res.ok) throw new Error('Network response not ok'); const d = await res.json(); // Update electricity rates if (d.usa_elec) LOCS.usa.en_rate = d.usa_elec; if (d.eu_elec) LOCS.europe.en_rate = d.eu_elec; if (d.india_elec)LOCS.india.en_rate = d.india_elec; // Update feedstock price (recalculate MATS multipliers relative to CPC baseline) if (d.coke_price_usd_t) { const newBase = d.coke_price_usd_t / 1000; // $/kg CHINA_BASE.raw_material = newBase * 1.30; // China CPC fraction of total RM } // Show live badge in header (if present) const liveBadge = document.getElementById('live-badge'); if (liveBadge) { liveBadge.style.display = 'inline-block'; liveBadge.textContent = '⬡ Live · Updated ' + new Date(d.updated).toLocaleTimeString(); } render(); // Re-render all charts with live data console.log('[Live] Data updated:', d.updated); } catch(e) { console.warn('[Live] Could not fetch live data, using defaults:', e.message); } } // Call on load, then every 6 hours fetchLiveData(); setInterval(fetchLiveData, 6 * 60 * 60 * 1000);

API keys (EIA, Fastmarkets, OXR) must never be in the browser-side HTML. They live only in server environment variables (.env on Vercel/Render or Azure Key Vault for enterprise).

▸ How to read this chart
China is shown as a flat dashed line — Chinese plants (BTR 432k tpa, Shanshan 340k tpa) operate at mature scale where the learning curve is exhausted. The blue (L1) and orange (L2) curves descend per Wright's Law as Western plants scale up. Cost gaps wider than ~22% cannot be closed by scale alone (capex/labor are structural).

▸ Cost model assumptions (calibrated to Bhuwalka 2025 Fig. 3)
China baseline (Acheson, calcined pet coke, uncoated):
• Total: $5,415/t (Bhuwalka 2025 Fig. 3b — "China synthetic" column).
• Capital share: 30.1% ($1,630/t). Operating share: 69.9% ($3,785/t).
• Key process inputs: petroleum coke $0.78/kg (14.4%), graphitization $2.36/kg (43.5% — electricity + packing coke + crucibles), coating $0.81/kg (14.9%), G&A $0.49/kg (9.1%).

United States baseline (Acheson, calcined pet coke, uncoated):
• Total: $12,312/t — 2.28× China (Bhuwalka 2025 Fig. 3a).
• Capital share: 50.6% ($6,228/t — 3.88× China). Operating share: 49.4%.
• Petroleum coke premium: $1.21/kg US vs $0.78/kg China (1.55×). Graphitization: 50.7% of total.

Wright's Law (volume scaling):
• Reference plant size: 25,000 tpa; learning rate: 15% per doubling (Ziegler & Trancik 2020 give 20–24% for Li-ion cells; graphite is more mature → 12–18% range; we use 15% mid).
• Floor: asymptotes to −22% below reference at very large scale (mature-industry single-line ceiling — Chinese plants >100k tpa already at this level).
• Curve range: 2,000 → 100,000 tpa; above 100k tpa requires multi-line plants.

▸ Quality vs. cost trade-off (degree of graphitization)
d₀₀₂ interpretation (interlayer spacing, Mering-Maire equation):
• Pure single-crystal graphite: d₀₀₂ = 0.3354 nm (DoG = 100%).
• Battery-grade synthetic anode: d₀₀₂ ≤ 0.3370 nm required (DoG ≥ 90%).
• Industrial graphite (electrodes, refractories): d₀₀₂ ≤ 0.339 nm acceptable (DoG ≥ 70%).

Process trade-off: Higher peak temperature and longer hold time push d₀₀₂ closer to 0.3354 (better quality) but consume more energy. EFB is the most energy-efficient (89% avg) and recent counterflow designs reach 2,700°C (AETC ACS Omega 2025; BNL pilot) — bringing DoG into battery-grade range (86–96%). LWG and VTF still achieve the highest DoG (95–99%) at moderate energy cost.

Sources: Emmerich 1995 (Carbon 33, 1709–1715); Ragan & Marsh 1983 (J. Mater. Sci. 18, 3161–3176); Wang et al. ACS 2025 (Tsinghua/Aramco, Acheson vs continuous comparison); AETC ACS Omega 2025 (doi:10.1021/acsomega.5c05566 — EFB peak 2,700°C validation).
⚙ Offset Engine — apply real-world corrections to the cost model
When to use offsets: The base model uses literature averages calibrated to Bhuwalka et al. 2025. Real suppliers deviate due to: (1) electricity contracts below grid average; (2) captive or spot feedstock pricing; (3) actual plant labor rates; (4) fully depreciated vs. new-build capital; (5) subsidies or IRA credits. Offsets propagate live to all cost calculations.

🇨🇳 China Import Duty — context-aware
Applies only when the importing market (L1 or L2) is non-China. Raises China's effective landed price as seen by L1's and L2's domestic markets — a "tariff wall" against Chinese-origin graphite. If L1 or L2 is China, no duty applies (China is the source, not the importer). Effect: shifts the China parity line upward in the Competitive Volume Curve and Cost Comparison table.
